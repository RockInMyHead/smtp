# Локальный редактор письма OpenFactory

Откройте файл **«Запустить редактор писем.command»** двойным щелчком. Он запустит локальный сервер и откроет страницу `http://127.0.0.1:8765/`. Окно Терминала должно оставаться открытым, пока вы работаете с редактором. Для остановки нажмите в нём Ctrl+C.

В редакторе можно указать получателя и тему, загрузить готовое письмо кнопкой **«Загрузить HTML-письмо»** (`.html` или `.htm`, до 15 МБ), включить правку текста прямо в предпросмотре, заменить любое фото или логотип в отдельном списке «Фотографии и логотипы» или нажатием на изображение в письме, а также открыть HTML-код. После загрузки проверьте письмо в предпросмотре и нажмите **«Сохранить»**, если хотите использовать его при следующем запуске. Изображения с относительными путями нужно заменить через редактор: они не попадут в письмо автоматически. Для замены используйте PNG, JPEG или GIF. Кнопка **«Скачать HTML»** сохраняет на компьютер текущую версию письма, включая ещё не сохранённые правки и встроенные изображения. Кнопка **«Сохранить»** записывает правки в `specmash_email_draft.html`; исходный `specmash_email_final.html` не меняется. Кнопка **«Вернуть исходный шаблон»** удаляет сохранённый черновик.

Для отправки введите пароль приложения Яндекс Почты один раз. После ввода он автоматически сохраняется в **Связке ключей macOS** для `news@open-factory.ru` и используется при следующих запусках без повторного ввода. Поле можно использовать для замены пароля; кнопка **«Удалить пароль»** удаляет его из Связки ключей. Пароль не сохраняется в файлах проекта, истории и GitHub. Сервис отправляет письмо через `smtp.yandex.ru:465` с проверкой TLS. Нужен доступ к SMTP без VPN, который блокирует или ограничивает это соединение.

Раздел **«История отправки»** показывает дату, адресата, тему и результат каждой попытки через локальный редактор. Кнопка **«Открыть письмо»** загружает сохранённую копию отправленного HTML для просмотра или повторного редактирования. История хранится только на этом компьютере в папке `local_history`, которая не публикуется в GitHub. Старые письма, отправленные до появления истории, в ней не появятся. Статус «Принято Яндексом» означает приём SMTP-сервером, а не гарантированную доставку получателю.

Если Python сообщает, что отсутствует `certifi`, один раз выполните в Терминале `python3 -m pip install certifi`, затем запустите редактор снова.

Сервис слушает только `127.0.0.1`, поэтому доступен лишь с этого компьютера. Отправка происходит только после нажатия кнопки и подтверждения адресата.
